SPECIAL TEAMS INTELLIGENCE V9.4 — STRICT PLAYER IDENTITY

RULE:
Historical PFF stats are shown only when identity is safely confirmed.

For 2025 stats to appear:
1. A current roster player must exist for the jersey number.
2. The official 2025 roster must contain exactly ONE player with that jersey number.
3. The 2025 player's normalized name must exactly match the current player's normalized name.

If any check fails, that player's historical stats are excluded entirely.

This deliberately prefers missing data over incorrect data.

It also protects against duplicate NCAA jersey numbers. If two 2025 players shared the same number, the program will not guess which player produced the PFF stats.

Current-season 2026 player cards continue to use the current roster.
